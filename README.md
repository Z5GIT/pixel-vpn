# Pixelgit

مدیریت ساده و سبک سرویس VLESS با پنل وب و ربات تلگرام.

## امکانات

- VLESS روی WebSocket و XHTTP
- ساخت کانفیگ با حجم، سرعت، IP و تاریخ انقضا
- گروه و لینک اشتراک
- QR برای لینک اتصال و اشتراک
- نمایش مصرف در کلاینت‌های سازگار با `subscription-userinfo`
- ربات تلگرام برای مدیریت و انتشار کانفیگ
- سهمیه رایگان روزانه ۱ گیگ برای کاربران عادی
- ساخت و ارسال کانفیگ‌های ۱ تا ۱۰۰ گیگ برای مدیر

## اجرا

```bash
pip install -r requirements.txt
python main.py
```

پس از اجرا، پنل روی پورت مقدار `PORT` در دسترس است.

## تنظیمات محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز پنل | `pixelgit` |
| `SECRET_KEY` | کلید ثابت سشن و رمزنگاری | خودکار |
| `DATA_DIR` | مسیر داده‌ها | `/data` |
| `PORT` | پورت HTTP | `8000` |
| `RAILWAY_PUBLIC_DOMAIN` | دامنه عمومی سرویس | `localhost` |
| `TELEGRAM_BOT_TOKEN` | توکن ربات | خالی |
| `TELEGRAM_ADMIN_IDS` | شناسه عددی مدیران، جدا با کاما | خالی |
| `TELEGRAM_CHANNEL_ID` | شناسه یا نام کاربری کانال | خالی |

## فرمان‌های ربات

فرمان‌های ثبت‌شده در منوی ربات فقط موارد لازم هستند:

- `/start` شروع
- `/help` راهنما
- `/free` دریافت ۱ گیگ رایگان روزانه
- `/post 1GB` تا `/post 100GB` ساخت و ارسال کانفیگ برای مدیر
- `/cancel` لغو عملیات جاری

ربات باید در کانال هدف دسترسی ارسال پیام داشته باشد.

## مصرف در Happ

برای لینک‌های اشتراک، هدر استاندارد زیر ارسال می‌شود:

```text
subscription-userinfo: upload=0; download=USED; total=TOTAL; expire=UNIX_TIMESTAMP
```

در صورت پشتیبانی کلاینت، مقدار مصرف، حجم کل و انقضا نمایش داده می‌شود.

## سلامت سرویس
